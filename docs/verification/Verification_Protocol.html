Introduction

This is a bench checklist for the Spine Cooling Runtime software. A tester walks through a normal (good-weather) session, then each error and warning the software can raise, and records Pass / Fail on this page. It is not a clinical procedure and must not be used with a patient.

Before beginning this verification, read the Operator guide to become familiar with device operation.

Run record

Cartridge seated, Level Low and Level Critical OK   CSF (Tip) ≥ 28 °C, Plate ≥ −10 °C   Leak sensor dry

1. Good-weather session

With the cartridge seated, coolant levels OK, and temperatures in range, run a normal session. Watch the status bar at the top of the screen for the current state (for example, Ready or Cooling). Use the START COOLING and STOP COOLING buttons to start and stop pumping. No error or warning should appear.

#ActionExpectedResultInit.
1 Start the device. Watch the status bar at the top of the screen. The status bar shows the state Init, then the state Ready. The START COOLING button is visible but cannot be pressed. No error or warning is shown. P F
2 Confirm the cartridge is seated and both level sensors are OK. Wait about 10 seconds after start-up. The status bar shows the state Cooling. The START COOLING button can be pressed. P F
3 Check the temperatures and pressures on the display, and confirm that the compressor is running. The readings update. The compressor is on while the state is Cooling. P F
4 Press the START COOLING button. Wait at least 30 seconds. The status bar shows the state Pumping. The button now reads STOP COOLING. The pump is running. No error or warning is shown. P F
5 Press the STOP COOLING button. Then press START COOLING and STOP COOLING once more. After STOP COOLING, the status bar shows the state Cooling and the pump stops. The START COOLING button can be pressed again. The second start/stop cycle behaves the same way, with no error or warning. P F

2. Level sensor failure

From the state Cooling or Pumping, trip a level sensor. The device must stop, show the error in the status bar, and keep the ACKNOWLEDGE ERROR button unusable until the levels are OK again.

#ActionExpectedResultInit.
1 Reach Cooling or press the START COOLING button so the status bar shows Pumping. The status bar shows the state Cooling or Pumping. No error is shown. P F
2 Make the Level Low sensor read not OK (leave Level Critical OK). The status bar shows the state Error and the message Level sensor failure detected. The pump and compressor stop. The ACKNOWLEDGE ERROR button is visible but cannot be pressed. P F
3 Tap the ⓘ next to the message in the status bar. A help window opens with causes and recovery steps. P F
4 Restore Level Low to OK. Press the ACKNOWLEDGE ERROR button. The ACKNOWLEDGE ERROR button can now be pressed. After it is pressed, the status bar shows the state Ready, then Cooling. P F
5 Return to Cooling or Pumping. Make the Level Critical sensor read not OK (leave Level Low OK). Restore it and press ACKNOWLEDGE ERROR. The same error message appears. After restore and acknowledge, the status bar returns to Cooling. P F

3. Cartridge removed during operation

Removing the cartridge while the device is cooling or pumping must stop the session and show the cartridge-removed error in the status bar.

#ActionExpectedResultInit.
1 Reach Cooling or Pumping. Unseat the cartridge (or make Cartridge In Place read not OK). The status bar shows the state Error and the message Cartridge removed during operation. The pump and compressor stop. The ACKNOWLEDGE ERROR button cannot be pressed. P F
2 Tap the ⓘ in the status bar. Try to press ACKNOWLEDGE ERROR while the cartridge is still out. Help opens. The ACKNOWLEDGE ERROR button stays unusable. The state remains Error. P F
3 Reseat the cartridge. Press the ACKNOWLEDGE ERROR button. The button can be pressed. The status bar shows Ready, then Cooling. P F

4. CSF low temperature

If CSF (Tip) falls below 28.0 °C while cooling or pumping, the device must stop. At exactly 28.0 °C it must not stop.

#ActionExpectedResultInit.
1 From Cooling or Pumping, set CSF (Tip) to 28.0 °C. The status bar still shows Cooling or Pumping. No error is shown. P F
2 Set CSF (Tip) to 27.9 °C or lower. The status bar shows the state Error and the message CSF low temp. The pump and compressor stop. The ACKNOWLEDGE ERROR button cannot be pressed. P F
3 Tap the ⓘ in the status bar. Raise CSF (Tip) to 28.0 °C or above, then press ACKNOWLEDGE ERROR. Help opens. After the temperature is back in range, the ACKNOWLEDGE ERROR button can be pressed. The status bar shows Ready, then Cooling. P F

5. Heat exchanger too cold

If the plate (heat exchanger) falls below −10.0 °C while cooling or pumping, the device must stop. At exactly −10.0 °C it must not stop.

#ActionExpectedResultInit.
1 From Cooling or Pumping, set the Plate temperature to −10.0 °C. The status bar still shows Cooling or Pumping. No error is shown. P F
2 Set the Plate temperature below −10.0 °C (for example −10.5 °C). The status bar shows the state Error and the message Heat exchanger too cold. The pump and compressor stop. The ACKNOWLEDGE ERROR button cannot be pressed. P F
3 Tap the ⓘ in the status bar. Return the Plate to a safe temperature, then press ACKNOWLEDGE ERROR. Help opens. After the plate is in range, the ACKNOWLEDGE ERROR button can be pressed. The status bar shows Ready, then Cooling. P F

6. Leak detected

Leak detection must be switched on for this test. A wet leak sensor held for at least half a second must stop the device. A brief flicker must not.

#ActionExpectedResultInit.
1 Switch leak detection on and restart if needed. Confirm the leak sensor is dry. Reach Ready or Cooling. No leak error is shown. P F N/A
2 Wet the leak sensor (or make it read wet) for less than 0.3 seconds, then dry it. The status bar does not show Error. No leak message appears. P F N/A
3 Keep the leak sensor wet for at least 0.5 seconds. The status bar shows the state Error and the message Leak detected. The pump and compressor stop. The ACKNOWLEDGE ERROR button cannot be pressed. P F N/A
4 Tap the ⓘ in the status bar. Dry the sensor, then press ACKNOWLEDGE ERROR. Switch leak detection back to its usual setting when finished. Help opens. After the sensor is dry, the ACKNOWLEDGE ERROR button can be pressed. The status bar shows Ready, then Cooling if the cartridge and levels are OK. P F N/A

7. Cooling ineffective

If the pump and compressor run for 10 minutes while CSF (Tip) does not fall by at least 0.2 °C, the device must stop.

#ActionExpectedResultInit.
1 Keep CSF (Tip) at a fixed value of 28 °C or above. Press the START COOLING button. Confirm the compressor is on. Record start time: __________ The status bar shows the state Pumping. The pump and compressor are running. P F
2 Do not let CSF (Tip) fall. Wait 9 minutes. The status bar still shows Pumping. The cooling-ineffective error has not appeared yet. P F
3 Continue until 10 minutes have passed. Record stop time: __________ The status bar shows the state Error and the message Cooling ineffective. The pump and compressor stop. P F
4 Tap the ⓘ in the status bar. Restore a normal CSF (Tip) reading if needed, then press ACKNOWLEDGE ERROR. Help opens. After acknowledge, the status bar shows Ready, then Cooling. P F

8. Sensor read failure

If a sensor board or cable fails while the device is running, the session must stop. On this test, the ACKNOWLEDGE ERROR button may be pressed even if the cable is still disconnected. Prefer a real device; skip this chapter if it cannot be done safely.

#ActionExpectedResultInit.
1 From Cooling or Pumping on the device, disconnect a live sensor cable. The status bar shows the state Error. The message is Sensor read failure or begins with Error during update:. The pump and compressor stop. Record the exact text: ________________ P F N/A
2 Tap the ⓘ in the status bar. Press the ACKNOWLEDGE ERROR button without reconnecting the cable. Help opens. The ACKNOWLEDGE ERROR button can be pressed immediately. The status bar leaves the Error state. P F N/A
3 Reconnect the cable. If Error returns, press ACKNOWLEDGE ERROR until the status bar shows Cooling. The device can be returned to the state Cooling. P F N/A

9. Fridge defect

A fridge defect must stop the device and show Fridge defect in the status bar. The current device does not yet report this signal. Mark N/A unless a later version provides a fridge-defect input.

#ActionExpectedResultInit.
1 If the device has a fridge-defect input, assert it while a session is running. The status bar shows the state Error and the message Fridge defect. The pump and compressor stop. The ACKNOWLEDGE ERROR button cannot be pressed until the defect is cleared. P F N/A
2 If there is no fridge-defect input, record N/A in Notes. N/A is marked. No other steps are required. P F N/A

10. Battery low (warning)

A low battery must show a warning only. The state must not change to Error, and pumping must continue. The current device does not yet report battery charge. Mark N/A unless a later version provides that reading.

#ActionExpectedResultInit.
1 If battery charge is shown, lower it below 20 % while in Cooling or Pumping. A warning shows Battery low. The status bar does not show the state Error. If the state was Pumping, the pump keeps running. P F N/A
2 Restore charge to 20 % or above (or reconnect power). The warning disappears. The state is unchanged. P F N/A

11. USB stick not present (warning)

If USB logging is on and the stick is pulled out without ejecting, a warning must appear. The session must not stop. Using the Eject button first must not show this warning.

#ActionExpectedResultInit.
1 Insert a USB stick labeled SPINELOGS. Wait until Service → Manual Operation shows that copying is active. No USB warning is shown. P F
2 Pull the stick out without using the Eject button. Stay in Cooling or Pumping. A warning shows USB stick not present. The status bar does not show the state Error. If the state was Pumping, the pump keeps running. P F
3 Reinsert the stick and wait for copying to resume. The warning disappears. P F
4 Press the Eject button under Service → Manual Operation, then remove the stick. The USB-not-present warning does not appear. P F

12. USB stick storage low (warning)

A SPINELOGS stick with less than 1 GB free must show a warning. The session must not stop.

#ActionExpectedResultInit.
1 Insert a SPINELOGS stick with more than 1 GB free. Record free space: __________ No USB storage warning is shown. P F
2 Eject the stick, fill it until less than 1 GB is free, and reinsert it. Record free space: __________ A warning shows USB stick storage below 1 GB. The status bar does not show the state Error. The USB-not-present warning is not shown (the stick is present). P F
3 Eject the stick, free more than 1 GB, and reinsert it. The warning disappears. P F

13. SD card storage low (warning)

If the device has less than 1 GB free for local logs, a warning must appear. The session must not stop. Do not fill the system disk until it is empty. If this cannot be done safely, mark N/A.

#ActionExpectedResultInit.
1 Record how much free space is on the device: __________ If more than 1 GB is free, no SD storage warning is shown. If less is already free, note the baseline. P F N/A
2 Add a large temporary file in the logs folder so that less than 1 GB is free. A warning shows SD card storage below 1 GB. The status bar does not show the state Error. P F N/A
3 Delete the temporary file so that more than 1 GB is free again. The warning disappears. P F N/A
